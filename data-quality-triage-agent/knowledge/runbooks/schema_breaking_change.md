# Runbook: cambio de esquema incompatible

Una regresión de esquema que rompe consumidores es P2; para sistemas críticos, escala según el procedimiento P1 si el flujo queda indisponible.

Compara el contrato registrado con el esquema observado y revisa el historial de despliegues. La coincidencia temporal no demuestra causalidad.
